# InterSaúde

Landing page da distribuidora de medicamentos **InterSaúde**.

## Como visualizar

Abra `index.html` no navegador, ou sirva a pasta localmente:

```bash
npx serve .
```

## Logo

A logo oficial está em `images/logo.png` (fundo transparente) e aparece no header e no footer.
Se o arquivo falhar ao carregar, o texto **InterSaúde** entra como fallback.

## Contato

Atualize no `index.html` (seção Contato):

- e-mail (`mailto:`)
- link do WhatsApp (`wa.me/...`)
